# 🍅 Pomodoro CLI Timer for Linux

A minimal and aesthetic terminal Pomodoro timer written in Python.

## Features
- 🎨 Centered ASCII-art clock (`figlet`)
- 🔔 Native desktop notifications (`notify-send`) + terminal bell
- 🔄 Session loop with manual cycle confirmation
- 🛡️ Clean exit on `Ctrl+C`

## Requirements
```bash
sudo pacman -S figlet libnotify
